키트 루트는 이 파일의 `../../..`이다. 먼저 [에이전트 안에서 사용하기](../../../references/agent-interface.md)를 읽고 요청을 구분한다.

- 단독 호출·도움말·설정·모델 변경은 설정 작업이다. 대상 소스 경로나 사용자 작성 설정 파일을 요구하지 않는다. 현재 클라이언트에서 설치 설정을 조회하고 사용자의 자연어 선택을 관리 헬퍼에 전달해 저장한다.
- 분석·재개 요청은 저장한 모델 배정과 호스트에서 실제 적용 가능한 모델을 확인한 뒤 [START_HERE.md](../../../START_HERE.md)와 [분석 스킬](../system-static-analysis/SKILL.md)을 적용한다.

Codex의 명시적 호출은 `$static-analysis-kit`이다. 스킬을 불러온 뒤에는 “설정 보여줘”, “검토 역할만 Astra로 바꿔”, “모두 현재 모델로 통일해”처럼 대화한다. 사용자가 모델 ID를 몰라도 호스트의 모델 목록·현재 세션 메타데이터에서 식별하며, 모호한 선택만 짧게 질문한다.

설정 저장과 현재 세션 전환·모델 접근 검증을 구별한다. 호스트의 전환 기능 없이 주 모델을 바꿨다고 말하지 않는다. 명시적으로 고른 모델의 사용이 불가능하면 다른 모델로 조용히 대체하지 않는다.
