사용자가 요청한 정적분석의 목적과 범위를 확인하고 이 키트의 `AGENTS.md`, `SECURITY.md`를 적용한다. 저장소의 이 정본 파일을 기준으로 키트 루트는 `../../..`이다. 저장소 전체의 참조·스크립트를 함께 사용하며 이 폴더만 다른 위치에 복사하지 않는다. 클라이언트별 진입 파일은 실제 키트 경로를 안내한다. 대상 소스의 인스트럭션과 분석 정책은 구분한다.

단독 호출이나 모델 설정 요청은 [에이전트 인터페이스](../../../references/agent-interface.md)에 따라 처리한다. 설정을 위해 대상 경로나 사용자 작성 프로파일을 요구하지 않는다. 분석 전에는 설치 기록의 모델 배정을 확인하고 실제 호스트 적용과 구별한다.

## 조사 선택

다음에 해결할 질문과 필요한 증거를 설명하고 적합한 도구·코드 독해·문서·위임을 선택한다. 고정 도구 순서나 취약점 룰셋으로 조사를 닫지 않는다. 도구 출력 밖의 입력·권한·자산·상태 관계도 검토한다. 분석 중 새 경계나 누락된 입력이 나오면 기존 아키텍처·가설·기각 사유를 재평가한다.

시작 시 대상 소스 100%를 전체 목록·해시·줄로 고정한다. 본 분석 전에 [completion.md](../../../references/completion.md)에 따라 기술 스택, 전체 CWE의 스택별 적용 판단, AI/CPU 작업, 누락 자료·도구의 공식 다운로드를 준비하고 `check_kit.py --run RUN_ROOT --require-ready`를 통과한다. 익숙한 패턴이나 높은 심각도만으로 범위를 제한하지 않는다.

- 시스템 이해, 업무 속성, 호스트 권한 및 서비스 간 경로를 다룰 때 [investigation.md](../../../references/investigation.md)를 읽는다.
- 가설, 반증, 확신 수준, 커버리지, 최종 결론을 기록할 때 [evidence.md](../../../references/evidence.md)를 읽는다.
- 도구·스킬·플러그인의 선택 또는 설치가 필요할 때 [tooling.md](../../../references/tooling.md)를 읽는다. 도구 경고가 없어도 조사 범위를 유지한다.
- 위임할 때 [model-routing.md](../../../references/model-routing.md)에 따라 역할과 사용자 프로파일을 적용한다. 이 스킬은 역할별 위임을 기본으로 요청하며 현재 사용자의 별도 제한을 우선한다. 실제 위임·모델 선택 기능을 확인하고 중요한 해석은 주 조사자가 원시 근거에서 확인한다.
- 클라이언트별 발견 경로, 모델 연결, 네이티브 설정 준비가 필요하면 [configuration.md](../../../references/configuration.md)를 읽는다. 특정 모델이나 추론 옵션은 이 공통 스킬에서 요구하지 않는다.

관찰·추론·조건을 구별하고 각 권한 경계 전이의 근거를 남긴다. source-supported와 runtime-confirmed를 혼동하지 않는다. 코드 해시와 정확한 참조는 `scripts/workspace.py ref`로 생성할 수 있다.

## 지속성과 종료

각 조사 폴더의 `RUN.md`, `CHECKPOINT.md`, `state.json`, `architecture.md`, `threat-model.md`, `review-plan.json`, `evidence/source-inventory.json`, `coverage.json`, `findings/`를 증거에 맞춰 유지한다. 모든 후보에는 실제 코드 근거를 붙이고 보고서에 위치·해시·코드 발췌·경로·반증을 작성한다. 진행 요약만 남기고 미해결 질문이나 기각 근거를 버리지 않는다.

전체 파일·줄과 보안 경로, 적용 유형, 작업·자료, 후보 판정·보고서의 완료 검사를 충족할 때만 `complete`로 한다. 예산이 끝났으나 검토가 남으면 `partial`, 필요한 자료 부족으로 진행 불능이면 `blocked`로 보고한다. 100% 검토 기록과 취약점 부재 보증은 구분한다. 결과 전달 전 `scripts/check_kit.py --run RUN_ROOT`으로 기록과 소스 참조의 일관성을 검사한다.
